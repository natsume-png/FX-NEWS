# FX-NEWS(FX見張り番)

為替(FX)に関係する情報を24時間自動で集め、日本語の解説と「どの通貨が上がりやすいか・下がりやすいか」の札をつけて、スマホに通知するプログラムです。自分用に作っています。

- 対象の通貨: 円・ドル・ユーロ・ポンド
- 集めるもの: 中央銀行の発表と講演、為替ニュース、要人の投稿、米国の大きな会社の決算の届け出、X(旧Twitter)の投稿、為替レートの急騰急落
- 解説と分類: Claude(Anthropic の AI。Haiku 5.5 という、速くて安い頭脳)
- 型ごとの成績: ニュースを「型」(例: 米国の経済指標・予想より強い)に分けて、届いたあとにドル円がどう動いたかを数えます(v0.3 から)
- 通知: 次の2つから選べます
  - ntfy(通知を受けるための無料アプリ。iPhone でも Android でも使える)
  - Pushover(通知ごとに音を選べる通知アプリ。有料で、スマホの種類ごとに1回払い)

**これは投資の助言ではありません。** 札(ドル円↑、円↑ など)は「この種類のニュースは、ふつうこう動きやすい」という見立てで、外れることがあります。型ごとの成績は「過去に何回どう動いたか」という事実の集計で、これからも同じように動くという約束ではありません。売り買いの判断は、ご自身でしてください。

## 仕組み

```
情報の出どころ                 見張り番プログラム(このレポジトリ)          スマホ
┌──────────────┐          ┌────────────────────────────┐        ┌──────────┐
│ 公式発表・ニュース │ 15秒〜3分│ 1. 新着だけを拾う                │        │          │
│ 会社の届け出(SEC) │ おきに見る │ 2. 同じ話・関係ない話を捨てる        │  通知   │  ntfy    │
│ 為替レート        │ ───────→ │ 3. Claude が解説・札・重要度をつける │ ─────→ │ Pushover │
│ X の投稿          │ 2秒おき/  │ 4. 重要度が高いものだけ通知する      │        │          │
└──────────────┘ 流れてくる  │ 5. あとで値動きと答え合わせする      │        └──────────┘
                          └────────────────────────────┘
```

通知の例:

```
ドル円↑｜FRB理事が、より強い引き締めを主張
型: FRB の人の発言・引き締め寄り｜この型のあとのドル円(15分後): 上げ4回・下げ2回。まだ6回なので、目安になりません(20回から)
FRBのウォラー理事が、物価の上昇をおさえるために、より踏みこんだ利上げが必要だと述べた。
▶ 米国の金利が上がるという見方が強まると、金利の高いドルが買われやすい。
ドル円は上がりやすい｜円↓ ドル↑ ユーロ→ ポンド→(見立て・確からしさ: 中)
要人発言・重要度 4/5・FRB の講演・02:57
原文: Fed's Waller calls for more aggressive action ...
```

- 見出しの先頭は、Claude の見立てです。ドル円の向きが読めたときは `ドル円↑` `ドル円↓`、読めなかったときは、動きそうな通貨の札(`円↑ ドル↓` など)を出します
- `↑` 上がりやすい / `↓` 下がりやすい / `→` 影響が小さい、または読めない
- 2行目は、同じ型のニュースが届いたあと、過去にドル円がどう動いたかの回数です(下の「型ごとの成績」)
- 重要度は 1〜5。はじめの設定では、3 以上だけスマホを鳴らします

## 型ごとの成績(v0.3 から)

「こういうニュースのときは、ドル円が上がる・下がる」を、思いこみではなく、数えて確かめるための仕組みです。

1. Claude が、ニュースを1件ずつ「型」と「向き」に分けます。型は14種類(米国の経済指標、FRB の決定、FRB の人の発言、日本銀行の決定、日本銀行の人の発言、日本の当局の円安けん制・為替介入、日本の経済指標、米国の政治・財政、日本の政治・財政、欧州・英国の中央銀行、欧州・英国の経済指標、戦争・事故・金融不安、株・金利・原油の大きな動き、その他)。向きは、型ごとに決まった言葉(予想より強い・弱い、引き締め寄り・ゆるめ寄り、など)です。
2. 為替の値を、1分ごとに記録します(円・ドル・ユーロ・ポンドの6つの組合せ)。
3. ニュースが**届いたとき**の値を起点に、5分後・15分後・60分後・1日後の値とくらべて、上がった回数・下がった回数・平均の動きを、型と向きごとに数えます。

数え方の決まり:

- 起点は、発表の瞬間ではなく、このプログラムが受け取った時刻(= スマホに届くころ)です。「知らせを見てから動いたら、どうだったか」を数えるためです。
- 日本時間の朝 6:00〜7:10 に届いたもの、その時間に答えが出るものは、数えません(売値と買値が大きく離れて、値がゆがむ時間のため)。
- 同じ型・同じ向きのニュースが30分以内に続いたら、最初の1回だけ数えます。前に出た話のくり返しも数えません。
- 発表から15分より後に届いた記事は、数えません(見張りを止めていたあいだの記事など)。
- 1日後は24時間後。相場が閉まっていたら(金曜のニュースなど)、72時間後(月曜の同じ時刻)で見ます。
- 20回に届かない型は、まだ目安にしません(たまたまの偏りと、見分けがつかないため)。
- 20回に届いた型は、3つの確かめをいっしょに出します: A. 別の通貨ペアでも同じ向きか / B. 届いた時間帯で分けても同じか / C. 大きな流れ(4時間前より上か下か)で分けても同じか。

成績の表は、`report.bat`(`python run.py report`)で見られます。見張りを動かしているあいだは、`data` フォルダの `seiseki.txt` にも、1時間ごとに書きなおします。本文も記録に残すので、型の決め方を変えたときは、過去の記事を分けなおせます。

## 必要なもの

| もの | 必須か | 説明 |
|---|---|---|
| Python 3.10 以上 | 必須 | プログラムを動かすための土台。追加の部品(pip で入れるもの)は使いません |
| ntfy か Pushover のアプリ | 通知を受けるなら、どちらか必須 | スマホに入れる通知アプリ。ntfy は無料。Pushover は有料で、通知の種類ごとに音を変えられます |
| Claude の API キー | あると解説がつく | ないときは、公式発表と決算だけを、見出しのまま知らせます |
| SEC に名乗る連絡先 | 決算の届け出を見るなら必須 | 名前とメールアドレス。米国 SEC の決まりです |
| X の Bearer Token | X を使うなら必須 | X は有料(受け取った投稿1件ごと) |

## 使い方(Windows)

フォルダの中のファイルをダブルクリックします。黒い画面(コマンドの画面)が開いて、日本語で結果が出ます。

| ファイル | すること |
|---|---|
| `check.bat` | 点検。それぞれの情報源に本当につながるかを、1回ずつ確かめます。通知は送りません |
| `setup-pushover.bat` | (Pushover を使うとき)番号を2つたずねて、ためしに1通送り、送れたら `config.ini` に書きます |
| `topic.bat` | (ntfy を使うとき)通知のあて先(ntfy の topic)を作って、`config.ini` に書きます |
| `setup-claude.bat` | Claude の鍵(API キー)をたずねて、つながるかを確かめ、つながったら `config.ini` に書きます |
| `setup-sec.bat` | 米国 SEC に名乗る連絡先(名前とメールアドレス)をたずねて、`config.ini` に書きます |
| `test-notify.bat` | ためしに、スマホへ通知を1通送ります |
| `try.bat` | お試し運転。いちばん新しい記事を「新着」としてあつかうので、すぐに通知が届きます |
| `start.bat` | 見張りを始めます。黒い画面が開いたままになります。止めるときは、黒い画面を閉じます |
| `start-hidden.bat` | 見張りを、黒い画面を出さずに裏で始めます。始まったかどうかを画面に出して、15秒で自動で閉じます |
| `status.bat` | 見張りが動いているかと、記録の最後の数行を出します |
| `stop.bat` | 裏で動いている見張りを止めます |
| `update.bat` | 見張りを止めて、もう一度始めます(プログラムを新しい版に入れかえたあとに使います) |
| `report.bat` | 型ごとの成績(ニュースが届いたあと、ドル円がどう動いたか)を出します |
| `autostart-on.bat` | 止まっても自分で始めなおす仕組みを入れます(下の説明) |
| `autostart-off.bat` | その仕組みを外します |

鍵や番号は、`setup-…` のファイルが黒い画面でたずねます。貼りつけて Enter を押すと、まず本当に使えるかを確かめて、使えたときだけ `config.ini` に書きます。

同じフォルダの見張りは、2つ同時には動きません(2つめは、何もせずに終わります)。

Mac や Linux では、同じことを `python3 run.py check` のように打ちます(`python3 run.py --help` で一覧が出ます)。

### 止まっても自分で始めなおす仕組み(Windows)

`autostart-on.bat` をダブルクリックすると、Windows の「タスク スケジューラ」(決めた時刻に物を動かす、Windows に入っている係)に、「FX-NEWS mihari」という仕事を1つ足します。

- 5分おきに、見張りが動いているかを見て、止まっていたら始めます。動いているあいだは、何も起きません(2つめは動きません)。
- パソコンを立ち上げなおしたあとも、サインインして5分以内に、自分で始まります。
- この利用者がサインインしているあいだだけ、この利用者として、ふつうの権限で動きます。管理者の権限は使いません。
- `stop.bat` で止めたときは、止めたままにします(`data` フォルダに `autostart.off` という目印を置きます)。`start-hidden.bat` で、また動かせます。
- 外すときは `autostart-off.bat` です。

### 黒い画面で、ほかのアプリの画面をかくしたくないとき(Windows)

- 見張りは `start-hidden.bat` で始めます。黒い画面は残りません。動いているかは `status.bat` で見られます。記録は `data` フォルダの `fxnews.log` に残ります。
- 点検や設定のときに開く黒い画面は、`config.ini` の `[general] console_rect` に「左,上,幅,高さ」(画面の点の数)を書いておくと、開いてすぐ、その場所に動きます。

## 設定

設定は2つのファイルに分かれています。

- `config.ini` … 鍵(かぎ)や通知のあて先など、人に見せないもの。**GitHub には置きません**(`.gitignore` に書いてあります)。見本は `config.example.ini`。
- `sources.json` … どこを見張るかの一覧。鍵は書きません。

`config.ini` のおもな項目(くわしい説明は `config.example.ini` の中にあります):

| 場所 | 項目 | はじめの値 | 意味 |
|---|---|---|---|
| `[claude]` | `api_key` | 空 | Claude の鍵 |
| `[claude]` | `monthly_cap_yen` | 2000 | 解説に使うお金の、1か月の上限(円)。届いたら解説なしになります |
| `[notify]` | `service` | ntfy | 通知を送るアプリ。`ntfy` か `pushover` |
| `[notify]` | `min_importance` | 3 | この重要度以上だけ通知します |
| `[ntfy]` | `topic` | 空 | ntfy の通知のあて先。`topic.bat` が自動で作ります |
| `[pushover]` | `user_key` / `api_token` | 空 | Pushover の受け取り番号と、送り主の番号。`setup-pushover.bat` がたずねて書きます |
| `[pushover]` | `sound_news` / `sound_important` / `sound_spike` / `sound_system` | incoming / bugle / spacealarm / mechanical | 通知の種類ごとの音(重要度3のニュース / 重要度4・5のニュース / 急騰急落 / プログラムからのお知らせ) |
| `[pushover]` | `daily_limit` / `monthly_limit` | 200 / 5000 | このプログラムが送る通知の、1日と1か月の上限(通) |
| `[pushover]` | `reserve` | 1500 | Pushover のアカウントぜんぶの今月の残りがこの数を切ったら、ニュースと急騰急落の通知を止めます |
| `[x]` | `bearer_token` | 空 | X の鍵 |
| `[x]` | `monthly_cap_yen` | 5000 | X に使うお金の、1か月の上限(円)。届いたら月が変わるまで止めます |
| `[x]` | `daily_cap_posts` | 300 | 1日に受け取る投稿の上限(件) |
| `[sec]` | `contact` | 空 | SEC に名乗る名前とメールアドレス |
| `[rates]` | `threshold_1m` / `5m` / `15m` | 0.08 / 0.15 / 0.30 | 急騰急落とみなす動きの大きさ(%) |
| `[general]` | `console_rect` | 空 | (Windows)黒い画面を置く場所と大きさ。「左,上,幅,高さ」 |

### Pushover を使うときの、送る数の上限

Pushover が送れる数は、1つのアカウントで月 10,000通までです(公式説明 https://pushover.net/api 。2026年5月から、そのアカウントの送り主ぜんぶで分け合う決まり)。使い切ると、月が変わるまで、同じアカウントのほかのプログラムの通知も送れなくなります。

そのため、このプログラムは次の3つで歯止めをかけます。

1. 1日の上限(`daily_limit`。はじめは 200通)
2. 1か月の上限(`monthly_limit`。はじめは 5,000通)
3. 残しておく数(`reserve`。はじめは 1,500通)。Pushover の返事に書かれている「アカウントぜんぶの今月の残り」がこの数を切ったら、ニュースと急騰急落の通知を止めます

上限で止めたときは、「FX見張り番からのお知らせ」で1日に1回だけ知らせます。

Pushover には、前に送った通知をあとから差しかえる仕組みがありません。そのため、急騰急落の「原因つき」は、音なしの2通目として届きます。原因の手がかりが見つからなかったときは、2通目を送りません。

## 急騰急落の見つけ方

- 為替レートを2秒おきに見て、いまのレートを「1分・5分・15分のあいだのいちばん高い値・安い値」とくらべます。決めた % 以上動いていたら知らせます。
- 1回きりのおかしな値で鳴らないよう、直近3回の真ん中の値を使います。
- どの通貨が動いたのか(例: 円がらみの3つが同時に下がれば「円が買われている」)と、直前のニュースをいっしょに出します。原因は断定しません。
- 1回知らせたら、その組合せは5分休みます(さらに 0.3% 以上動いたときは別)。

## お金がかかるところ

| 項目 | 目安 | 上限のかけ方 |
|---|---|---|
| Claude の解説と型分け | 1件あたり約0.1円(読ませる4,000・書かせる450トークンで計算。Haiku 5.5 は、100万トークンあたり、読ませるのが 0.10ドル・書かせるのが 0.50ドル。1ドル160円) | `[claude] monthly_cap_yen` |
| X の投稿 | 1件 0.005ドル(約0.8円) | `[x] monthly_cap_yen` と `daily_cap_posts`。X の管理画面でも上限を設定してください |
| ntfy、為替レート、公式発表、ニュース | 無料 | 無料の ntfy.sh は1日250通まで |
| Pushover | アプリは有料(スマホの種類ごとに1回払い)。送るのは月 10,000通まで無料 | `[pushover] daily_limit`・`monthly_limit`・`reserve` |

上限は、このプログラムが自分で数えて守ります。ただし数え方が相手とずれることもあるので、X と Claude それぞれの管理画面でも、上限を設定しておくのが安全です。

## 守っている決まり

- 相手のサイトに負担をかけないよう、変更がないときは中身を送ってもらわない取り方(条件つきの取得)を使い、同じ相手にはつないだままの接続を使い回し、つながらないときは間隔をあけてやり直します。
- 米国 SEC には、連絡先を名乗ってから取りに行きます(SEC の決まり。1秒に10回まで)。
- 自分で使うための道具です。集めた記事や投稿を、ほかの人に配ることは考えていません。配る場合は、それぞれの情報源の利用の決まりを確かめる必要があります。
